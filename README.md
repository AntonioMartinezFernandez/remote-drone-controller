# remote-drone-controller

This project is a remote drone controller that utilizes WiFi and the CRSF (Crossfire Serial Protocol) to communicate with drones. It is built using an ESP32 microcontroller and an F4DC flight controller, programmed in C++ and Golang.

Currently, the project is in the development phase, and the code is available on GitHub. The controller allows users to control their drones remotely using a WiFi connection, providing a seamless and efficient way to operate drones without the need for traditional radio controllers.

The software components of this project consist of a C++ library for handling the CRSF protocol and a Golang application that serves as the user interface for controlling the drone. The ESP32 microcontroller acts as the bridge between the WiFi network and the drone's flight controller, enabling real-time communication and control.
